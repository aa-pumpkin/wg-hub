# WG Hub для Android

Нативное приложение (Kotlin + Compose Multiplatform). Работает с тем же сервером, что и сайт.

- `shared/` весь код экранов и логики. Потом из него же собирается iPhone, нужен Mac.
- `androidApp/` тонкая обёртка для Android.
- Тексты берутся из `frontend/src/locales` при каждой сборке (`scripts/sync-texts.mjs`), поэтому переводы на сайте и в приложении одинаковые. Тексты только для приложения лежат там же, в разделе `app`.
- Все экраны сайта есть и в приложении.
- Без сети приложение показывает последние сохранённые данные. Отметки задач («сделано», «пропустить», «вернуть», «передать»), «куплено» в покупках и «+1» посудомойки копятся и уходят на сервер, когда связь появится. Создание и правка (задач, покупок, событий, расходов и т. п.) работают только при связи.

Сборка, все инструменты лежат в `../.tools`:

```bash
./build-android.sh        # готовый файл: ../WG-Hub.apk
```

Проверка в эмуляторе на тестовом сервере (порт 8090, адрес из эмулятора `http://10.0.2.2:8090`): `scripts/phone.py` нажимает кнопки по тексту и делает скриншоты в `shots/`.

Любое изменение делается сразу и на сайте, и здесь.
