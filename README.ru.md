# WG Hub

Приложение для совместной жизни в WG: обязанности с автоматической ротацией, список покупок, календарь, заметки и общие расходы. Интерфейс на немецком, английском и русском, у каждого участника свой язык, светлая и тёмная тема, работает на телефоне и устанавливается как PWA.

## Запуск

Нужен только Docker:

```bash
docker compose up -d --build
```

Приложение откроется на <http://localhost:8080>. База и миграции поднимаются сами, данные хранятся в Docker-томе и переживают перезапуск.

Посмотреть на заполненную WG (необязательно):

```bash
docker compose exec backend node dist/scripts/seed.js
```

Появятся логины `anna` (админ), `max` и `lisa` с паролем `demo12345`.

## Как устроено

- **Вход без почты:** логин и пароль, работают на любом устройстве. Забытый пароль: админ WG выдаёт одноразовую ссылку на 24 часа.
- **Основные задачи:** меняются каждый понедельник, срок до воскресенья 23:59 по времени WG. Каждая задача переходит по часовой стрелке к следующему человеку в круге.
- **Заморозка:** участник может заморозить себя на время отъезда, админ может заморозить любого, раздел «Участники». Новых задач ему не назначается, открытые задачи этой недели переходят к другим, место в круге сохраняется.
- **Дополнительные задачи:** свой ритм, по умолчанию раз в месяц, и свой список людей.
- **Покупки и долги:** товар добавляется кнопкой и помечается «для WG» или «только для меня». Кто отметил покупку, тот и платил: он вводит цену, и расход появляется сам. Покупка для WG делится на всех, кроме замороженных, личную должен тот, кто просил. Без цены долга нет, возврат товара в список удаляет расход.
- **Долги:** тот, кому должны, может простить долг или потребовать вместо денег пиво. Цену пива задаёт админ. Долг закрывается, когда он подтвердит, что пиво получено.
- **Посудомойка:** необязательный счётчик, включается в «Настройках WG». Каждый отмечает себя сам. Цикл заканчивается, когда на всех наберётся заданное число (по умолчанию 20): у кого больше всех, получает корону, кто ни разу не разобрал, получает страйк и теряет 10 очков.
- **Очки:** за выполненную вовремя задачу начисляются полные очки, с опозданием половина. Есть уровни, серии недель, награды и рейтинг.

Основные задачи, круг и очки редактирует только админ, раздел «Уборка» → «План».

Админ может выключить «Режим админа» (боковая панель, на телефоне раздел «Ещё») и пользоваться приложением как обычный участник. Настройка своя для каждой WG и каждого устройства.

## Настройка

Всё необязательно для пробного запуска. Для настройки скопируйте `.env.example` в `.env`:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_PORT` | `8080` | Порт приложения |
| `POSTGRES_PASSWORD` | `wghub` | Пароль базы, только латиница и цифры (он входит в URL подключения). Задаётся до первого запуска: Postgres применяет его только при создании тома |
| `APP_ORIGIN` | пусто | Публичный URL, нужен только если прокси подменяет заголовок `Host` |
| `RATE_LIMIT_AUTH_MAX` | `20` | Лимит попыток входа и регистрации с одного IP в минуту |

### Развёртывание на сервере

1. Задайте свой `POSTGRES_PASSWORD` в `.env`.
2. Поставьте перед приложением TLS-прокси (Caddy, Traefik, nginx), который передаёт `Host` и `X-Forwarded-Proto`. Cookie сессии получит флаг `Secure` автоматически.
3. Не открывайте порт приложения наружу мимо прокси.

За внешним прокси все запросы выглядят как пришедшие с одного IP, поэтому лимит на вход становится общим на всех. Если это мешает, настройте `set_real_ip_from` в `frontend/nginx.conf`.

### Администрирование

```bash
# Сброс пароля, если забыл сам админ WG (обычно ссылку выдаёт админ в разделе «Участники»)
docker compose exec backend node dist/scripts/reset-password.js anna 'новый пароль'

# Резервная копия базы
docker compose exec db pg_dump -U wghub wghub > backup.sql

# Обновление
docker compose up -d --build   # миграции применяются при старте backend
```

## Разработка

```bash
npm install
npm run db:up                    # Postgres на localhost:5432
cd backend && npx prisma migrate deploy && cd ..
npm run seed                     # демо-данные, необязательно
npm run dev                      # API :3000, Vite :5173
```

Откройте <http://localhost:5173>. Настройки backend лежат в `backend/.env` (образец: `backend/.env.example`).

| Команда | Что делает |
|---|---|
| `npm test` | Все тесты. Для backend нужен запущенный `npm run db:up`, база `wghub_test` создаётся сама |
| `npm run build` | Проверка типов и production-сборка |
| `cd backend && npx prisma migrate dev --name <имя>` | Новая миграция после изменения схемы |

Подробности: [архитектура](docs/ARCHITECTURE.md).
